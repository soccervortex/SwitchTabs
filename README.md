# 🔀 Desktop Switcher (Numpad Hotkey Tool)

A simple and lightweight Windows utility built with AutoHotkey that lets you switch between virtual desktops using your Numpad keys.

## 🎯 Features

- ➡️ **Numpad 2** — Switch to the next virtual desktop (Ctrl + Win + →)
- ⬅️ **Numpad 1** — Switch to the previous virtual desktop (Ctrl + Win + ←)
- 🪶 Lightweight and fast (compiled AutoHotkey EXE)
- 🖥️ Designed for Windows 10 and 11 virtual desktop users

## 📦 Download

👉 [Download the latest release here](https://github.com/soccervortex/SwitchTabs/releases)

> No installation needed — just download and run the EXE.

## 🚀 How to Use

1. Download the EXE file from the [Releases](https://github.com/soccervortex/SwitchTabs/releases) section.
2. Double-click the file to launch it.
3. Press:
   - `Numpad 2` to switch to the **next desktop**
   - `Numpad 1` to switch to the **previous desktop**
4. The script runs in the background — you’ll see a "Tabs" icon in the system tray.

## 🔧 Requirements

- Windows 10 or Windows 11
- Numpad on your keyboard (external or built-in)
